## 🤖 AI & Biometrics

### face-api.js
*   **License**: [MIT](https://github.com/justadudewhohacks/face-api.js/blob/master/LICENSE)
*   **Description**: JavaScript API for face detection and face recognition in the browser implemented on top of tensorflow.js.
*   **Usage**: Powering the Edge AI Kiosk for landmark detection and biometric matching.

### TensorFlow.js
*   **License**: [Apache-2.0](https://github.com/tensorflow/tfjs/blob/master/LICENSE)
*   **Description**: A library for machine learning in JavaScript.
*   **Usage**: Underlying engine for facial recognition models.

## 🛡️ Security & Infrastructure

### Helmet.js
*   **License**: [MIT](https://github.com/helmetjs/helmet/blob/main/LICENSE)
*   **Description**: Express middleware for securing apps by setting various HTTP headers.
*   **Usage**: Hardening the API against XSS, Framing, and CSP-related attacks.

### Vite PWA Plugin
*   **License**: [MIT](https://github.com/vite-pwa/vite-plugin-pwa/blob/main/LICENSE)
*   **Description**: Progressive Web App support for Vite.
*   **Usage**: Enabling offline resilience and caching for the factory kiosk.

### Vite Basic SSL
*   **License**: [MIT](https://github.com/vitejs/vite-plugin-basic-ssl/blob/main/LICENSE)
*   **Description**: Support for self-signed certificates in local development.
*   **Usage**: Enabling secure camera access on mobile devices during testing.
